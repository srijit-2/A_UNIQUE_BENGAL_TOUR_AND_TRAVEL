## 🌿 About Sundarbans

The Sundarbans is the world's largest mangrove forest and a UNESCO World Heritage Site, renowned for its rich biodiversity and the iconic Royal Bengal Tiger. The region offers unique wildlife experiences, river cruises, birdwatching, and an authentic glimpse into the natural beauty of eastern India.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/sundarbans-sparkle-site.git
```

Navigate into the project:

```bash
cd sundarbans-sparkle-site
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
